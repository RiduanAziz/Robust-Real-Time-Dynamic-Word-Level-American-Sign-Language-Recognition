    SignFlow: Robust Real-Time Dynamic Word-Level American Sign Language Recognition¶

    Comprehensive Internship Final Project Report¶

    Project Title: Robust Real-Time Dynamic Word-Level American Sign Language Recognition Using Landmark Kinematics, Prior-Guided Fusion, and Calibrated Probability Ensembles
    Student / Intern Name: Riduan Aziz
    Organization / Department: Machine Learning & Computer Vision Research Team
    Supervisors / Mentors: Senior ML Systems Architect & Computer Vision Lead
    Academic / Internship Period: 2026
    Repository: GitHub: RiduanAziz/Robust-Real-Time-Dynamic-Word-Level-American-Sign-Language-Recognition
    Primary Benchmark: World-Level American Sign Language 100-Class Benchmark (WLASL-100)

    Abstract¶

    Word-level American Sign Language (ASL) recognition in uncontrolled real-world environments presents profound computer vision challenges, including fast non-rigid hand articulation, high interpersonal signer variability, severe modality asymmetry, and extreme class overlap. Existing RGB video-based approaches (such as 3D Convolutional Neural Networks) impose excessive computational burdens (~500 ms/sample) that prohibit deployment on edge devices, while raw coordinate-based graph networks frequently degrade under missing or occluded hand detections.

    This project delivers SignFlow, an end-to-end, high-performance, and verifiable machine learning system for real-time word-level ASL recognition. Through systematic exploratory data analysis of 2,038 WLASL-100 sequences and 21,083 nationwide landmark archives, we uncover critical real-world phenomena: pose and face landmarks exhibit high stability (>97% visibility), whereas non-dominant hands are absent in up to 67.5% of signing frames. To overcome these challenges, we designed and implemented: 1. A 553-keypoint Holistic Landmark Normalization & Feature Pipeline (1,659 coordinates spanning body pose, face mesh, and bilateral hands) backed by mathematically sound visibility masking. 2. An adapted Uni-Sign Prior-Guided Fusion (PGF) architecture that leverages body/face anatomical priors to guide hand attention alongside score-aware reliability gating. 3. A 3-Way Probability-Level Calibrated Ensemble combining baseline temporal BiGRUs, deep regularized BiGRUs, and cross-attentive PGF models.

    Tuned strictly on the validation partition (\(N=337\)) via a 3-simplex grid search with zero test-set leakage, our ensemble achieves a new defensible benchmark on the official WLASL-100 held-out test split (\(N=257\)): 76.65% Top-1 Accuracy (+2.33% over baseline), 91.44% Top-5 Accuracy (+2.72% over baseline), 94.16% Top-10 Accuracy, a Macro-F1 of 0.7558, and cuts the Expected Calibration Error (ECE) by 47.6% down to 0.0838. We successfully deployed this pipeline into a production-grade, full-stack assistive workstation featuring an asynchronous FastAPI WebSocket engine, a modern React/TypeScript glassmorphism frontend, dynamic model switching, and real-time multi-camera streaming operating at ~31.7 ms inference latency (~42.5 FPS).

    1. Introduction and Problem Motivation¶

    1.1 Context and Significance¶

    Over 70 million deaf and hard-of-hearing individuals worldwide rely on sign languages as their primary medium of communication. Despite advances in automatic speech recognition (ASR) for spoken languages, dynamic sign language recognition (SLR) remains drastically underserved. Sign language is not a simple sequence of static finger gestures; it is an expressive, multidimensional language consisting of: - Manual Features: Dynamic trajectory of the hands, finger shape conformations, and palm orientations. - Non-Manual Markers: Facial expressions, lip patterns, eye gaze, and head movements that act as critical grammatical markers. - Spatial Anchors: Body torso and shoulder alignments that provide the spatial context against which signs are articulated.

    1.2 Core Engineering and Scientific Challenges¶

    Developing an interactive, real-time, word-level ASL recognition system faces five fundamental roadblocks: 1. Modality Occlusion and Asymmetry: Signers frequently perform one-handed signs or cross hands over the body, causing camera self-occlusion. In standard models, missing keypoints default to zero coordinates, creating artificial high-velocity motion vectors that corrupt temporal representations. 2. Computational Constraints in Assistive Tech: Deploying heavy 3D-CNNs (e.g., I3D, SlowFast) directly on client laptops or web browsers introduces unviable latency (>400 ms), high power consumption, and frame lag. 3. Severe Signer Contamination in Published Research: Standard public splits often mix the same signer across training and test partitions, resulting in inflated academic metrics that collapse when exposed to novel signers in real-world environments. 4. Model Overconfidence & Calibration: Softmax probabilities in standard neural networks often exhibit high calibration error, producing misleading certainty on erroneous predictions. 5. Training-Serving Skew: Discrepancies between preprocessed offline datasets and real-time streaming camera frames degrade runtime accuracy.

    1.3 Project Objectives¶

    The overarching objectives of this internship project were to: - Establish a reproducible, deterministic ML training and evaluation pipeline on the WLASL-100 benchmark. - Conduct deep exploratory data audits to identify dataset leakage, class imbalance, and landmark detection characteristics. - Implement novel deep learning architectures incorporating anatomical prior guidance and reliability gating. - Build a zero-leakage probability ensemble achieving superior accuracy and calibration over historical baselines. - Develop a full-stack, real-time web application with sub-40 ms latency, dynamic model selection, and multi-camera support.

    2. Literature Review & Theoretical Background¶

    2.1 Video-Based vs. Landmark-Based Recognition¶

    Prior research in sign language recognition broadly falls into two categories:

    Approach Typical Architectures Pros Cons
    RGB Video-Based 3D-CNNs (I3D, SlowFast), Video Transformers (TimeSformer) Captures subtle texture, lighting, and ambient context. High parameter counts (>25M), severe compute costs (~500 ms/sample), privacy risks.
    Skeletal / Landmark-Based Spatial-Temporal Graph Networks (ST-GCN), BiGRUs, Spatial Transformers Lightweight, privacy-preserving, fast inference (<35 ms), focus purely on kinematics. Sensitive to joint estimation noise, requires robust normalization.

    In this project, we adopted a holistic landmark-based approach, leveraging MediaPipe's high-efficiency keypoint extractors to achieve low latency while extracting geometric representations from 553 holistic keypoints.

    2.2 WLASL Benchmark Landscape (Protocol A - 100 Classes)¶

    To understand our position in the scientific literature, we benchmarked against published results on WLASL-100:

    To ensure consistent tensor operations without losing dynamic information, we adopted a standardized sequence length of \(T=64\) frames using temporal linear interpolation and causal zero-padding.

    4. Methodology & Engineering Architecture¶

    4.1 Holistic Landmark Normalization & Feature Engineering¶

    SignFlow processes raw MediaPipe landmarks through a multistage geometric normalization pipeline: 1. Torso Centering: Coordinates are translated such that the midpoint between the left and right shoulders resides at the origin \((0, 0, 0)\). 2. Scale Invariance: Distances are normalized by the Euclidean distance between the left and right shoulders (\(d_{\text{shoulder}}\)). 3. Engineered Kinematic Representation (365 Dimensions): - Base Hands + Pose: \(21 \times 3 \times 2 + 33 \times 3 = 225\) dimensions. - Wrist-Relative Hand Coordinates: \(21 \times 3 = 63\) dimensions per hand (\(126\) total). - Inter-Wrist Vector & Distance: \(3 + 1 = 4\) dimensions. - Fingertip Extensions: Euclidean distances from fingertips (thumb, index, middle, ring, pinky) to the respective wrist (\(5 \times 2 = 10\) dimensions). - Strict Masking Contract: Derived features are masked to zero unless both participating landmarks have non-zero visibility flags, preventing ghost artifacts.

    4.2 Candidate Neural Architectures¶

    1. Baseline BiGRU (robust_holistic_fusion)¶

    • Architecture: 2-layer Bidirectional Gated Recurrent Unit (hidden dimension 128, dropout 0.3).
    • Input: Flattened 1,659-dim holistic coordinates.
    • Temporal pooling: Attentive temporal pooling aggregating hidden states across the sequence.

    2. Uni-Sign Prior-Guided Fusion Classifier (UniSignPGFClassifier)¶

    Adapted from the ICLR 2025 research (Uni-Sign: Prior-Guided Fusion for Dynamic Sign Language Recognition, arXiv:2501.15187): - Isolated Anatomical Encoders: Four separate 1D convolutional residual blocks project Left Hand, Right Hand, Body Pose, and Face Mesh independently into latent dimension \(d=64\). - Prior-Guided Cross-Attention: Body pose and face mesh act as spatial Keys and Values, while hand feature representations act as Queries. This explicitly answers: "Where are the hands moving relative to the face and shoulders?" - Score-Aware Reliability Gating: Computes an empirical reliability score \(r_m = \frac{1}{T} \sum_{t=1}^T \mathbf{1}(\|\mathbf{x}_{m, t}\| > 0)\) for each hand. The attention outputs are scaled by \(r_m\), gracefully suppressing noise when a hand is absent. - Classification Head: Kinematic BiGRU temporal aggregation followed by layer normalization and linear projection.

    3. Deep BiGRU with Maximum Regularization (wlasl100_max_accuracy)¶

    • Deeper hidden capacity (embedding dimension 96, hidden dimension 128).
    • Trained with Label Smoothing (\(\epsilon = 0.08\)) and a Cosine Annealing Learning Rate Scheduler over 200 epochs to prevent overconfidence.

    5. Calibrated Ensembling & Zero-Leakage Validation¶

    5.1 Ensembling Theory & Objective¶

    Rather than relying on a single model's inductive bias, we combine the complementary strengths of our three distinct paradigms: $\(\mathbf{P}_{\text{ensemble}} = w_1 \mathbf{P}_{\text{Baseline}} + w_2 \mathbf{P}_{\text{UniSign}} + w_3 \mathbf{P}_{\text{DeepBiGRU}}, \quad \text{where } \sum_{i=1}^3 w_i = 1, \; w_i \ge 0\)$

    5.2 Mathematical Formulation of Metrics¶

    • Top-\(k\) Accuracy: $\(\text{Top-}k = \frac{1}{N} \sum_{i=1}^N \mathbf{1}(y_i \in \text{top\_k\_indices}(\mathbf{p}_i))\)$
    • Expected Calibration Error (ECE): $\(\text{ECE} = \sum_{m=1}^M \frac{|B_m|}{N} \left| \text{acc}(B_m) - \text{conf}(B_m) \right|\)$ where predictions are grouped into \(M=10\) confidence bins \(B_m\).

    5.3 Zero-Leakage Validation Grid Search¶

    To ensure rigorous scientific integrity, optimal weights \((w_1, w_2, w_3)\) were discovered through an exhaustive 3-simplex grid search evaluated strictly on the 337 validation samples (validation_manifest.json): - Search Space: \(w_i \in [0.0, 1.0]\) with step size \(\Delta = 0.05\), constrained to \(w_1 + w_2 + w_3 = 1.0\). - Validation Result: Optimal configuration \((w_1=0.25, w_2=0.10, w_3=0.65)\) achieved 78.34% Validation Top-1 (264 / 337 correct). - The weights were then locked and applied in a single forward pass to the 257 held-out test samples.

    6.3 Qualitative Disambiguation Analysis¶

    • thin vs clothes: The baseline model confused these signs due to identical vertical finger-pinching motion. Uni-Sign PGF's hand-to-pose cross-attention disambiguated the wrist elevation relative to the collarbone/shoulders, allowing the ensemble to correctly classify thin.
    • who: Circular chin articulation previously obscured by minor head orientation shifts was resolved by the deep BiGRU's temporal smoothing, converting a test error into a correct prediction.
    • 16 Perfect Classes: Achieved 100% precision and recall (\(F_1 = 1.0\)) on 16 vocabulary classes: computer, go, chair, walk, fine, yes, hot, orange, mother, now, white, family, hearing, dance, table, and apple.

    SignFlow is not merely a research prototype; it is engineered as a robust, low-latency, full-stack assistive workstation.

    flowchart LR

    B -->|WebSocket JSON Packets| C[FastAPI Async Server]
    C -->|Frame Buffer & Normalizer| D[Feature Representation Pipeline]
    D -->|Active Model Switcher| E{Inference Engine}
    E -->|Route 1| F[3-Way Calibrated Ensemble]
    E -->|Route 2| G[Uni-Sign Prior-Guided Fusion]
    E -->|Route 3| H[Deep BiGRU / Baseline]
    F & G & H -->|Top-K Logits & ECE| I[WebSocket Response]
    I -->|Live Telemetry & TTS| J[React 18 Glassmorphism UI]

    7.1 Backend Infrastructure (FastAPI + PyTorch)¶

    • WebSocket Streaming (/ws/live): Bidirectional, low-overhead WebSocket transport with bounded frame buffering (\(T=64\)).
    • Dynamic Model Hot-Switching (/models/available & /model/switch): Allows clients to seamlessly switch between the 3-Way Ensemble, Uni-Sign PGF, and BiGRU models without restarting the service.
    • Sub-35ms Latency Budget:

    Total End-to-End Glass-to-Glass Latency ~31.7 ms (~31.5 FPS)

    • Dark AI-Workstation Aesthetics: Professional dark theme (bg-slate-950) featuring translucent glassmorphism containers, neon cyan/emerald telemetry accents, and responsive layout.
    • Interactive Controls:
    • Model Selector Dropdown: Real-time switching between active architectures with immediate backend synchronisation.

    8. Critical Discussion, Rigorous Audits & Limitations¶

    8.1 Uncovering Signer Contamination in Published Research¶

    During our dataset audit, we uncovered a significant methodological flaw in standard WLASL benchmarks: - Protocol A (Official Benchmark Partition): 104 out of 105 test signers (99.0%) appear in the training split. Models evaluated under Protocol A benefit from recognizing the physical body proportions of known individuals. - Protocol B (Signer-Independent Partition): We constructed data/manifests/signer_disjoint/, enforcing zero signer overlap. When evaluating on completely unseen signers, accuracy naturally declines, highlighting the true out-of-distribution challenge of dynamic sign recognition.

    8.2 Discovered Implementation Discrepancies and Repairs¶

    During the internship pipeline audit, we discovered and resolved three critical discrepancies: 1. Engineered Feature Dimension Mismatch: The feature dimension was declared as 280, but the concatenation code generated 365 features. We updated the contract, added visibility propagation, and locked it with automated regression tests (test_features_contract.py). 2. Vocabulary Index Alignment: Configuration files had disparate label orderings, causing an apparent drop to 9.30% when evaluating with unaligned YAML files. We established a canonical hash-locked vocabulary across all configurations. 3. Modality Visibility Dropout: Missing hands caused arbitrary zero-velocity jumps. Resolved via the score-aware gating mechanism in Uni-Sign PGF.

    9.1 Summary of Contributions¶

    Through this internship project, we: 1. Successfully reproduced and validated the WLASL-100 baseline at 74.32% Top-1 accuracy. 2. Designed and adapted an ICLR 2025 Uni-Sign Prior-Guided Fusion network achieving state-of-the-art calibration (ECE 0.0561). 3. Created a zero-leakage 3-Way Probability Ensemble achieving 76.65% Top-1 and 91.44% Top-5 accuracy on the official held-out test benchmark. 4. Backed every component with 19 automated regression tests and comprehensive documentation.

    9.2 Future Research Roadmap¶

    • Continuous Sign Language Recognition (CSLR): Expanding from isolated word recognition to continuous sentence translation using Connectionist Temporal Classification (CTC) and causal language modeling.
    • On-Device Edge Acceleration: Compiling the ensemble weights to ONNX Runtime / WebAssembly for complete client-side, serverless browser execution.
    • Multi-Signer Few-Shot Adaptation: Implementing test-time normalization to adapt to unseen signers in fewer than 3 calibration frames.
